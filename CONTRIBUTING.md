# Contributing to Universal Job Auto-Apply Bot

Thank you for your interest in contributing to the project! We welcome code contributions, issue reports, and documentation improvements.

---

## Code of Conduct
Please be respectful, collaborative, and considerate of all contributors.

---

## Getting Started

1. **Fork** the repository and clone your fork locally.
2. **Create a branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Install dependencies**:
   ```bash
   pip install -r backend/requirements.txt
   cd frontend && npm install
   ```
4. **Make changes & run tests**:
   - Backend tests: `pytest backend/tests/`
   - Frontend tests: `npm test`
5. **Commit your changes** following conventional commit syntax:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `docs:` for documentation
   - `refactor:` for code restructuring without feature change
   - `test:` for test additions or updates
6. **Submit a Pull Request** with a detailed explanation of your changes.
